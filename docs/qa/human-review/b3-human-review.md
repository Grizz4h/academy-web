### HR-B3-C2 — Wirkung Zeit / Raum / Optionen

| Feld | Wert |
|------|------|
| **claim_id** | B3-C2 |
| **Ort** | B3_D2 |
| **Claim** | Unmittelbare Wirkung des Drucks: Zeit, Raum, Optionen, oder kein Effekt |
| **Warum HR** | Zentrale Wirkungssprache Track A/B; Puckgewinn bewusst ausgeschlossen |
| **Was prüfen** | Drei-plus-kein-Effekt zu grob? Optionen vs. Raum doppelt? |
| **AI-Evidence** | MODERATE — IIHF time and space |
| **Offene Frage** | Mehrfachwirkung erlauben oder eine dominante Pflicht? |
| **human_status** | `NEEDS_CHANGE` |
| **human_notes** | Die Wirkung des ersten defensiven Zugriffs wird weiterhin getrennt vom späteren Ergebnis betrachtet. Verwendet werden die beobachtbaren Kategorien Zeit eingeschränkt, Raum eingeschränkt, Handlungsoptionen eingeschränkt, kein klarer unmittelbarer Effekt und Unklar. Pro Szene wird die am deutlichsten sichtbare unmittelbare Wirkung gewählt. Eine Mehrfachauswahl wird nicht eingeführt, weil Zeit, Raum und Handlungsoptionen häufig gleichzeitig oder aufeinander aufbauend eingeschränkt werden und eine Mehrfachauswahl die Vergleichbarkeit der Beobachtungen verschlechtern würde. Die gewählte Kategorie behauptet weder eine alleinige Ursache noch den Gesamterfolg der Defensivaktion. Ein späterer Puckgewinn, Abschluss oder ein Gegentor darf die Klassifikation nicht rückwirkend bestimmen. Kein klarer unmittelbarer Effekt bedeutet, dass der Gegner seine Aktion zunächst ohne erkennbare Einschränkung fortsetzen konnte. Unklar bedeutet, dass Szene oder Perspektive keine zuverlässige Beurteilung erlauben. Die Begriffe müssen mit den B2-Beobachtungsdimensionen abgestimmt und im Hover-over-Glossar einheitlich erklärt werden. Nach geprüfter Umsetzung kann der Status auf CONFIRMED_AS_RINQ_MODEL gesetzt werden.|

### HR-B3-C3 — Support-Taxonomie

| Feld | Wert |
|------|------|
| **claim_id** | B3-C3 |
| **Ort** | B3_D3 |
| **Claim** | Timing (sofort/verzögert/keine) + Funktion (Passweg/Raum/Druck/Übernahme) |
| **Warum HR** | Stärkstes RinQ-Raster in B3; nicht IIHF-Liste |
| **Was prüfen** | Funktionen vollständig genug? Staffelung als eigene Option fehlen? |
| **AI-Evidence** | MODERATE partial |
| **Offene Frage** | „Gegner übernehmen“ vs. „Druck aufrechterhalten“ klar genug für Nutzer? |
| **human_status** | `NEEDS_CHANGE` |
| **human_notes** | B3_D3 wird entsprechend der bereits beschlossenen Verschiebung der defensiven Center-Aufgaben aus B1 als zentrale defensive Unterstützungsperspektive geschärft. Das Timing wird mit Sofortige Unterstützung, Verzögerte Unterstützung, Keine Unterstützung erkennbar und Unklar erfasst. Die sichtbaren Unterstützungsfunktionen lauten Zentrum schützen, Passweg schließen, Mitspieler beim Zugriff unterstützen, Gegenspieler übernehmen und Unklar. Mitspieler beim Zugriff unterstützen bezeichnet einen zweiten defensiven Impuls, durch den der erste Zugriff gemeinsam getragen oder fortgesetzt wird. Gegenspieler übernehmen bezeichnet die erkennbare Zuordnung zu einem anderen angreifenden Spieler und ist davon zu unterscheiden. Das bisherige Druck aufrechterhalten wird durch Mitspieler beim Zugriff unterstützen ersetzt. Das bisherige Raum absichern wird durch das konkretere Zentrum schützen ersetzt. Staffelung bleibt ein beschreibendes Prinzip für Abstände und Positionierung, wird aber nicht als zusätzliche Unterstützungsfunktion angeboten. Die Auswahl beschreibt sichtbares Verhalten und behauptet weder ein festes System noch eine vorgegebene Center-Verantwortung in jeder Situation. Theorie, Drill, Feedback, Auswertung und Hover-over-Glossar müssen dieselbe Taxonomie verwenden. Interne IDs nach Möglichkeit stabil migrieren; keine blinde globale Textersetzung durchführen. ### HR-B3-C4 — Sequenz-Strukturlabels

| Feld | Wert |
|------|------|
| **claim_id** | B3-C4 |
| **Ort** | B3_D4 |
| **Claim** | Struktur bleibt / verschiebt sich kontrolliert / bricht / unklar |
| **Warum HR** | Reine RinQ-Klassifikation; „kontrolliert verschieben“ leicht wertend |
| **Was prüfen** | Drei Outcomes + unklar didaktisch tragfähig? |
| **AI-Evidence** | MODERATE (Konvention) |
| **Offene Frage** | Reflection-Option „gute Unterstützung“ → „rechtzeitige Unterstützung“? |
| **human_status** | `NEEDS_CHANGE` |
| **human_notes** |Die Sequenzklassifikation bleibt als RinQ-Modell erhalten, wird aber neutraler und weniger kausal formuliert. Die sichtbaren Hauptkategorien lauten Struktur bleibt erhalten, Struktur wird angepasst, Struktur geht verloren und Unklar. Das bisherige Struktur verschiebt sich kontrolliert wird ersetzt, weil „kontrolliert“ bereits eine Qualitäts- oder Absichtsbewertung enthält. Struktur bricht auseinander wird durch das neutralere Struktur geht verloren ersetzt. Eine erhaltene oder angepasste Struktur bedeutet nicht automatisch eine erfolgreiche Defensive; ein Strukturverlust bedeutet nicht automatisch, dass die gesamte Defensivaktion schlecht war. Die Frage „Was war der entscheidende Moment?“ ist zu kausal und wird durch „Welche Veränderung war dabei sichtbar?“ oder eine gleichwertige beobachtbare Formulierung ersetzt. Die zugehörigen Optionen sollen sichtbare Veränderungen beschreiben, beispielsweise Unterstützung wird sichtbar, zentraler Raum bleibt geschützt, Gegner löst den Druck, Abstände werden größer und Unklar. Die Reflexion gute Unterstützung wird entfernt, weil sie pauschal wertet. Stattdessen soll gefragt werden, welche Unterstützung sichtbar war und wie sich die Struktur anschließend entwickelte. Theorie, Aufgabenstellung, Feedback, Auswertung und Hover-over-Glossar entsprechend angleichen. Nach geprüfter Umsetzung kann der Status auf CONFIRMED_AS_RINQ_MODEL gesetzt werden. |
